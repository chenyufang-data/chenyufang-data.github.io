# cyfang.org

Chenyu Fang's homepage: static pages, no build step, no tracking. Served by GitHub Pages from this repository
(`chenyufang-data.github.io`), HTTPS enforced; DNS at GoDaddy.

| File | What it is |
|---|---|
| `index.html` | the homepage: pitch, selected work, research, toolkit, education |
| `cv/index.html` | the full CV (cyfang.org/cv/): every project in detail; "Save as PDF" prints a clean copy |
| `og.png` | the 1200x630 card LinkedIn, Slack and email show when a link is pasted |
| `favicon.svg` | the "CF" tab icon |
| `CNAME` | tells GitHub Pages the site is cyfang.org |

No résumé PDFs are published here. The three focused versions (AIE, MLE, ASci) go with applications and to
referrers who agreed to refer.

## Update

Edit the HTML, commit and push; the site updates within a minute. Every number on both pages comes from the
résumés and the project notes, so change them together.
